# ماه‌افزار هوشمند رسا (mahai.ir)
Frontend: React 19 + Vite 8 + Tailwind + PWA + i18next (fa/en)
Backend:  Flask 3 + JWT + SocketIO + Flask-RESTX + SQLAlchemy + Waitress

## اجرای محلی
Backend:  cd backend ; .venv\Scripts\activate ; pip install -r requirements.txt ; python run_waitress.py  -> http://127.0.0.1:5000
Frontend: cd frontend ; npm install ; npm run dev  -> http://localhost:3000

## انتشار
بسته mahai_release_v2_*.zip را آپلود کنید و deploy/SERVER_COMMANDS.txt را اجرا کنید.
